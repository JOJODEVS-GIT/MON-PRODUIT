## 📖 Description

Tableau de bord de **gestion et rentabilité de produits** : saisie des coûts (achat, pub, livraison…), calcul automatique du **bénéfice** et du **ROI**, statut de rentabilité, **simulateur de volume**, graphiques et export CSV. Les données sont conservées localement (localStorage).

Le projet a été **migré d'un fichier HTML/CSS/JS statique vers une application Vue 3** (Composition API + Vite), en conservant **le rendu et le comportement à l'identique**.

## 🔗 Démo

- **Site en ligne :** https://mon-produit.vercel.app

## 🛠️ Technologies

- **Vue 3** (Composition API, `<script setup>`) + **Vite**
- **Chart.js** (graphiques bénéfice & répartition)
- **localStorage** (persistance)
- CSS personnalisé (thème sombre)

## ✨ Fonctionnalités

- 📦 Tableau éditable en ligne (achat, vente, pub, livraison, autres, notes)
- 🧮 Calcul automatique du **bénéfice** et du **ROI** + statut (Rentable / Faible / Perte)
- 📈 KPIs en temps réel + graphiques (barres & anneau)
- 🔍 Recherche, filtre par statut, tri par bénéfice / ROI
- 🧪 Simulateur de volume de ventes
- ⬇️ Export CSV · 🔔 notifications toast · 💾 sauvegarde locale
